# 💰 Cryptoverse 

Bu projede; HTML5, CSS3 ve Bootstrap kullanılarak geliştirdiğim, modern ve duyarlı (responsive) bir kripto borsa sitesi projesidir. Farklı cihazlarda sorunsuz çalışan bir yapı oluşturulmuştur. Bootstrap ile hızlı ve uyumlu bir tasarım sağlanmış, hover efektleri ile siteye canlılık katılmıştır. <br/>
